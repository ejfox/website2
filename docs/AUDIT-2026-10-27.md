# Code audit findings (2026-10-27)

Found while adding headers and comments to every file (branch
`chore/readable-codebase`). Nothing here has been fixed; that pass changed
comments only. "Confirmed" means the coordinator re-checked it against the
code or prod. Everything else was read from the code by an agent and is
worth checking before acting on it.

Security findings from this pass are tracked privately, not in this public repo.

## Content pipeline
- **Orphan cleanup never runs** (confirmed): getFilesRecursively(outputDir, '.json') ignores its 2nd arg and returns .md only, so the sweep and the sealed exemption never fire. CLAUDE.md says it works. A naive fix would also delete goodreads-stats.json, rides/ and index.json.
- One failed post: its catch pushes nothing to `results`, so every later manifest entry is off by one (reported by the agent; not yet checked by me). processStats.errors is never printed; the run exits 0.
- getPostType gets an absolute path in processMarkdown(), so folder-based types never match (manifest passes the slug correctly).
- LQIP placeholders are fetched from Cloudinary but never used in HTML.
- Bare wikilink titles title-case the slug instead of reading the target post.
- On-this-day year uses local time, day key uses UTC (Jan 1 off by one).
- A prediction embedded in a post goes stale until that post is reprocessed.
- Dead exports: DEFAULT_PLUGINS, most of config.mjs, stats.mjs, helpers.mjs.

## pages/*/ (nested)
- reading/[slug].vue renders book.content, but the JSON only has `html`, so highlights never render.
- gear: the affiliate check reads item.amazon (the column is Amazon_URL); JSON-LD uses item.Slug (no such column), so URLs come out /gear/0..n; PRIORITY_CONTAINERS names 'WLF Enduro Backpack' but the CSV has 'WLF Enduro Pack Vest'.
- blog/[...slug].vue: the redirect branch is dead; errors are swallowed to null, so the error block never shows; smartSuggestions is computed but never rendered.
- /photos EXIF overlay never shows (/api/photos lacks those fields).
- tag/[...slug].vue: project/reading captions show /blog/<slug> but link to /<slug>; a projects-only tag shows the list AND "No content found".
- /scraps ships the full ~3.4MB scrap list in every SSR payload.
- robots notes: titles stuck at opacity-0 (the reveal animation was deleted).
- rides/[slug] clock has no time zone; the index pins New York.
- server/api/predictions/[id].ts has no visibility check of its own (not yet checked whether its loader filters private predictions).
- GitHub repo data only refreshes on a local `yarn github:export` + commit (prebuild skips it in CI).

## utils / composables / plugins / config
- Unescaped innerHTML/v-html: utils/statsSummary.ts (Last.fm artist), plugins/link-previews.client.ts (/api/og siteName and image URLs, i.e. third-party page data), footnotes-to-sidenotes (textContent back into innerHTML).
- statsSummary links #movies; the section id is `films`.
- isScheduled() is hand-copied into processMarkdown.mjs, nuxt.helpers.ts and atprotoRkey.mjs; useProcessedMarkdown's own visibility checks skip `sealed`.
- tailwind spacing: overridden keys are 8px steps but unlisted ones keep the 4px default, so p-5 (20px) < p-4 (32px).
- Two attribution systems: utils/attribution.ts and utils/firstTouch.ts.
- prediction-refs plugin mounts apps without the Nuxt context and never unmounts them; video-viewport never disconnects its observer.

## server/ (utils, middleware, routes)
- /tags.json: prod appears to serve the static public/tags.json (alphabetical, static etag), so the journalist-pyramid route doesn't reach anyone. CLAUDE.md describes it as working.
- robots-rss.xml channel link is /robots; the page is /blog/robots.
- utils/postFilters.ts isHiddenFromListings uses `??`: a top-level draft:false masks metadata.draft:true (confirmed; low likelihood given the manifest shape).
- server/utils/flashcards.ts loadDeck(id) puts the router param into the path unsanitized (`.csv` suffix forced, so at worst it reads other CSVs).
- sitemapEntries has its own hand-copied visibility list (no sealed check; safe only because sealed posts never reach the manifest).
- Feeds: undated posts handled three ways; both main feeds slice 50 before filtering.
- photos.epub takes the /api/photos origin from the Host header and caches the result for everyone.
- server/utils/fetch.ts timeout ends at headers; a slow body can hang fetchJSON.

## scripts/ (meta, author, blog, qa, og-image)
- author/shoot-queue.mjs spawns scripts/author/capture.mjs, but the file is scripts/capture.mjs: every upload fails. capture.README.md has the same wrong path.
- author/predict-pro.mjs gitCommit(): statement in a double-quoted shell string (a quote, `$` or backtick breaks/injects); `git commit` takes anything else staged; SHA written back after commit leaves the file dirty.
- meta/lint-frontmatter-safety.mjs ends `main().catch(console.error)`: a crash exits 0 and lets deploys through.
- author/send-webmentions.mjs: no draft/hidden/unlisted/password/publishAt filter (would ping for a scheduled post); `!url.includes('ejfox.com')` filter is loose; failures exit 0.
- CLAUDE.md calls meta/vault-repo-merge.mjs read-only; `--apply` writes vault + content/blog.
- Hardcoded absolute vault paths in vault-repo-merge, frontmatter-sync-report, gen-gear-annex, blog/import-sealed.
- og-image: `--all` advertised but not handled; watermark ~54px left; 3 unused exports.
- qa/layout-review.mjs: unknown viewport crashes; wipes the --out dir each run.
- meta/content-report.mjs: opens the HTML report (focus steal) by default; identical if/else branches; String.replace with JSON breaks on `$&`.
- meta/unify-cloudinary-text.mjs: checkpoint written before data/_tool-cache/ exists.
- Stale hints mention blog:import (seal-links, lint-frontmatter-safety); create-prediction writes predictions/<year>/ vs flat; shiki theme mismatch in markdownToHtml.

## pages/ (top level)
- Renaming a page file isn't caught by anything (check-urls covers post routes only). A rename needs a manual 301.
- /predictions/** prerender rule bakes nothing (no slug list, crawlLinks off).
- bookmarklet.vue pastes the passphrase raw into a JS string: a quote or backslash breaks it.
- on-this-day.vue is prerendered, so its HTML shows the build day and ignores ?month/?day until hydration.
- atlas.vue: possible race. It awaits /api/atlas before listening for map `load`; if the map loads first, there are no overlays.
- gists.vue: header stats count only the current page; probable double fetch on page change.
- following.vue footer names ~/.newsboat/urls; prod reads data/blogroll.urls.
- index.vue "today" is UTC, not Eastern.
- stats.vue: unused refs and .fade-* styles; wordsThisMonth is always 0.
- consulting.vue: fallback copy says "Q1/Q2 2025"; floating CTA → #book vs sidebar → #cal-inline-embed. A testimonial says "fmr Meta" (the quoted person's employer, not a client), so check it against the NDA rule.
- external-links.vue: API returns bare [] when the CSV is missing; NaN% at zero links.

## components/
- GistPreview fallback puts raw gist text into v-html unescaped (own gists, so self-XSS); `import.meta.server || import.meta.client` is always true, so highlight runs twice.
- AnimatedNumber ignores duration/ease/delay/priority/startValue, which callers pass ~45 times. The animation is a fixed 600ms.
- MonkeyTypeStats checks averageWPM but the API sends averageWpm, so that tile never shows.
- WebVitalsReporter listens for an event nothing dispatches, so it never renders.
- StatsDataState callers pass `state=`, but the prop is `type` (harmless only because the default matches).
- GearStats: formatWeight rounds (30oz → "2lb 14.0oz"); AVG WT divides by containers, not items.
- NextAvailableSlot: `refresh:` isn't a useFetch option, so there's no 5-min refresh.
- LastFmStats topGenres is always empty; RescueTime calendar always shows fallback data; GitHub streak counts from the last commit, not today.
- PredictionCard/Ref display sha256 hashes that don't reproduce.

## server/api (other)

- gist-stats `totalLines` is always 0; chess `recentGames` returns the month's
  oldest 10; weekly-summary fetches port 3000 in dev (the dev server is on
  3006); now.get.ts reads film.link/date, which don't exist.
- cal/availability fails open (reports all slots free when Cal.com is down);
  consulting-availability has a hardcoded "Q1 2025" fallback.
- atlas/private/sky can load 500k rows against the 1G pm2 cap.
- The orphan-route test counts comments as callers, so a comment that names

  but doesn't exist.
