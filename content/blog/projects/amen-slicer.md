A breakbeat slicer / performance instrument for the Game Boy Advance — 13 amen flavors, sync-locked clock, live stutters/FX/crush, and a reactive generative visualizer. Butano/C++

I am SO stoked about this one. This is basically because I am getting my music table set up again — I have a Maschine+ and an FM synthesizer, and I just need a device that makes it easy to drop in, beat sync, and chop up amen breaks in time with the other music hardware.

I made one for the Game Boy Advance to experiment with making my own Game Boy game utilities — or really, shaping the Miyoo Mini into my own dream piece of hacker music gear.

Plug in the Game Boy — the headphone port is a little janky but you can get it — then sync up the 1 from the Game Boy, pick a sample, chop it around while the other instruments happen.

I also made a Rust macOS amen slice breaker app that works with the 64-pad grid controller over MIDI — [amen-grid](https://github.com/ejfox/amen-grid).
